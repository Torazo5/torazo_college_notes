# Formal charge

$$
\text{Formal charge} = \#\text{ valence e}^- - \#\text{ lone pair e}^- - \#\text{ bonds}
$$

Low formal charge = stable. 0 optimally but sometimes we have to sacrifice.

> [!warning] Electrons, not pairs
> [[quiz prac]] writes this as "loose pair count - bonded pairs", which is ambiguous — [[Reading 1 - Sep 3]] has it as lone pair **electrons**. Worth settling which before a quiz.
