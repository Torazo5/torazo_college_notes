# N+1 rule

$n$ is NOT just the group next door — $n$ = total count of every proton within $\leq 3$ bonds, added up across all groups

two exclusions:
- protons equivalent to the one im watching dont count (the other H's on my own carbon)
- only valid as one $n+1$ if the J's are similar, otherwise multiply $(n_{1}+1)(n_{2}+1)$

n+1 gives lines INSIDE one signal, not n+1 signals
